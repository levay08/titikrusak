# titikrusak.id

titikrusak.id adalah platform crowdsourcing interaktif untuk melaporkan dan memantau kondisi
infrastruktur publik yang rusak di Indonesia (seperti jembatan, jalan, sekolah,
prasarana publik, dan utilitas), dengan memanfaatkan kolaborasi antar warga dan otoritas terkait menggunakan verifikasi identitas melalui e.id untuk keamanan, transparansi dan keefektifan laporan secara terpusat

## Tech Stack

- Frontend: React (Vite), Tailwind CSS, Leaflet.js
- Backend: Node.js, Express
- Database: SQLite (better-sqlite3)
- Identitas: e.id Verifier API
